# Novo Mundo

Chat com texto, imagens e voz para um grupo de amigos. Site estático (HTML, CSS e JavaScript puros), com Supabase para login, banco e mensagens em tempo real, e WebRTC para a voz.

- Servidores e canais de texto com mensagens ao vivo e envio de imagem
- Canais de voz direto entre os participantes (P2P), com mudo e indicador de quem fala
- Convite por link (`?convite=CÓDIGO`)
- Instalável como app (PWA)
